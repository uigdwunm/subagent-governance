- 类型：明确小修复；父任务与一个子 Agent。
- 历史需求：轮数只接受约定的 ASCII 正整数形式，不能因 Unicode 数字判断差异放行其他字符；不改变 none/all、默认值或其他原生参数语义。
- 候选业务起点：`e7bb27e1a0979691ae4f56c06e575f4e346cb228`；后续修复定位 `2e9ccbd118c7ccb1051a623018561cd0d4378647`。
- 允许范围：原生适配器的轮数校验及直接相关行为测试；父任务审查并验收。不混入同次历史提交的 Hook 输出修复。
- 验收项：合法 ASCII 形式保持接受；零、前导零、超长及非 ASCII 数字按契约拒绝；none/all 和省略语义不变；证据区分本地行为与真实平台投递。
- 材料准备：确认历史基线能复现，提取当时适用业务契约、模块及必要依赖；不携带后续修复或验收答案。首次复现属后续实验材料验证，本轮未做。
- 风险：新版 Skill 明示字符约束，任务说明必须向两组等量提供该需求；安装包还可能暴露实际解法。简单度可能更适合父任务直做，选样时必须复核派发收益，不能强制保留。
