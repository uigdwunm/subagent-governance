## 场景与契约

W 下分为 `child`、`parent`、`evidence` 三个目录。派发前 `child/shipping.py` 仅提供抛出 `NotImplementedError` 的入口。父任务准备独立验收程序，子任务禁止读取或修改 `parent` 和 `evidence`。

唯一目标是实现 `shipping_fee(weights_grams, zone)`，治理等级 standard，接口 collaboration_turns。允许修改 `child/shipping.py` 和 `child/test_shipping.py`，使用 Python 标准库；禁止修改开发仓库、插件或外部服务，不引入第三方依赖。

完成条件如下：

1. 返回整数分；local 每计费公斤 400 分，remote 每计费公斤 700 分。
2. 重量容器必须为 list，每项是 1–30000 的整数且拒绝 bool；空列表费用为 0；地区必须为 local 或 remote 字符串；非法输入均抛 `ValueError`。
3. 计费取整由父任务选择 A（逐包裹向上取整后相加）或 B（总重合并后向上取整）；子任务不得自行决定。
4. 交付实现和 unittest，覆盖两个地区、整公斤、非整公斤、空列表及非法输入，说明测试结果和剩余事项。

父任务的有效后续决定是 **B**：按合单发货计算。例如 `[1,1]` 的 local 费用为 400 分，`[1001,999]` 的 remote 费用为 1400 分。关闭后精确 status 的原始快照仍保留 A/B 待定契约；本段保存后续实际约定，避免将快照误当成全部最终要求。

没有另向子任务灌输通信动作或预设终态答案；执行规则来自一次 prepare 生成的 `spawn_args.message`，其中自带普通问题使用进行中消息、继续独立工作和终态交付义务。
